# Разработка и воспроизведение

База кандидата: Cloudscape 0.5.7-sharp.1,
SHA256 F4E77D987BC9FB67785D1736CA4E639D4CC22D263AF19EB3495FC730B9A490DF.

Релизная заморозка: весь Java/GLSL и все значения по умолчанию сохраняются.
Допустимое отличие JAR кандидата — версия в fabric.mod.json.
`tools/verify-payload.py baseline.jar candidate.jar --output payload.json`
проверяет весь состав архива, включая классы и ресурсы, а не только поле форм.

Сборка: `build.ps1`, зависимости: `dependencies.lock.json`.
JDK 25.0.2+10 использован при приёмке. Lock фиксирует полный набор
компиляционных зависимостей; это не список обязательных пользовательских модов.
Бинарники зависимостей и чужие исходники в source ZIP не включаются.
Для побайтного воспроизведения нужна та же версия JDK; две независимые сборки
проверяются SHA256 и сравнением распакованных payload.

CPU-проверки находятся в `validation/cpu`. Они проверяют конфиг/транзакции,
адаптер/интерфейс шейдера, режимы атласа, диагностику, кеш, погоду и ветер.
Проверка восьмичасовой симуляции не заменяет восемь часов реальной игры.
Умышленно испорченные фикстуры печатают ожидаемые ERROR/WARN; итог определяется
кодом завершения и result.json, а не отсутствием слова ERROR в общем логе.

Игровой код проверки находится в `validation/game`. Это отдельный development
мод. Он не входит в JAR Cloudscape. Локальный launcher использует отдельный
gameDir, фиктивный токен для demo-режима и копию фиксированного тестового мира.
Он не подключается к сторонним серверам и не использует пользовательские миры.
Для запуска стенда нужны собственные отдельно установленные игровые файлы;
скрипт подготовки стенда и точные команды находятся в локальном отчёте приёмки.

GPU-прогоны строго последовательны. FPS измеряется без записи видео,
после прогрева; дождевые переходы исключаются из окон. Сохраняются все
попытки, сырые времена кадров, параметры и SHA256 JAR каждого прогона.
Неудачный контроль не заменяется после просмотра выгодного результата
кандидата; критерии задаются до сравнения. Изменение допуска оформляется
отдельным исследованием с исходным отрицательным результатом.

Перед установкой: закрытый Minecraft, проверенный JAR, резервная копия JAR и
точных байтов конфига, один Cloudscape JAR в mods. Откат проверяется на отдельном
каталоге. Чекпойнты погоды сохраняются в копии, но автоматически не откатываются,
чтобы не терять более новую фазу мира.
