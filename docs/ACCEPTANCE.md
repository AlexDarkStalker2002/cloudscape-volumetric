# Приёмка Cloudscape 0.5.7-rc.1

Кандидат подготовлен для локальной beta-приёмки. Публичная публикация не выполнялась.
JAR SHA256: `99A0C9B63E4A0658E327E894A7C7344817D6F0016AF9049D73E192874339FDE4`.

Формы, настройки по умолчанию и весь код рендера сохранены: 39 Java-классов и 11 ресурсов побайтно совпадают с принятой 0.5.7-sharp.1. В JAR изменена только версия в fabric.mod.json.

## Выполнено

- 12 CPU-наборов: конфиг/транзакции, адаптер/контракт, кеш/атлас/диагностика, погода и ветер. Симуляция 8 ч × 4 seed является CPU-проверкой, а не восьмичасовой игровой сессией.
- Независимая сборка в другом каталоге дала тот же SHA256.
- Реальная игровая сессия 60 минут: 6 перезагрузок Iris, Overworld/Nether/End, один выход и повторный вход, дождь, гроза, ночь, виды внутри. Exit 0, нативных crash-логов в этом прогоне нет.
- Чистые новые миры и полный сценарий UI на Microsoft Java 25.0.1 и Temurin 25.0.2 со штатными JVM-параметрами игры. Только Iris/Sodium/Cloudscape и отдельный development-проверяющий мод; обязательные Fabric API-подмодули встроены в Sodium.
- Меню, применение, отмена, пресеты, перезагрузка и ресурсы; Unbound без лишнего атласа; неподдержанный интерфейс пака с сохранением исходных облаков; игровые сцены движения и окклюзии.
- 18 проверок установки/отката и 3 проверки запрета установки при активном клиенте на отдельных фикстурах. Пользовательские файлы и миры не участвовали в этих мутациях.
- 3 пары FPS по 9 сцен; 30 с кадров на сцену. Сырые времена кадров, GPU-запросов и P95/P99 сохранены.

Приняты пары 1, 2 и 4. Пара 3 целиком исключена до агрегатного анализа: в сцене 18 кандидата очередь DH была 1/3. Обе версии повторены по тому же протоколу, без выбора запусков по полученному FPS. Исходная невалидная пара сохранена.

RTX 5070, NVIDIA 616.92, Microsoft Java 25.0.1, Minecraft 26.3, Fabric 0.19.5, Iris 1.11.7, Sodium 0.9.2, DH 3.3.4, Complementary Reimagined r5.9.3. Разрешение 2560×1440, native 16 / simulation 6 / DH 64, cap 180, VSync off. Выборки 192/64/8, воксель 16, дальность 6000, атлас 4096, ветер 4. Смена сухой облачности отключена только в FPS-копиях для повторяемости; ветер и морфинг работают. Дождевой переход исключён из окон. GPU-timer охватывает GameRenderer, а не всю GPU-работу процесса.

## Исправления стенда и сохранённые отрицательные попытки

В раннем дополнительном запуске ошибочно удалялся `-XX:StackShadowPages=32`. Это штатный параметр Minecraft 26.3, что проверено по [официальному version.json Mojang](https://piston-meta.mojang.com/v1/packages/61fff1316bd50312624a858bbb5eb18fa45208ed/26.3.json). Temurin без него дал 0xc0000005 ещё до мира; то же воспроизведено без Cloudscape. После восстановления параметра прошли 4 контрольных запуска (2 без / 2 с Cloudscape) и полноценные чистые миры/UI на обеих Java. Качество, код мода, драйвер и глобальные настройки не менялись. Это исправление запуска стенда; универсальное исправление любых исторических JVM-сбоев не заявляется.
Первая попытка Unbound вызвала assertion проверяющего мода до первого отрисованного конвейера. Стенд дождался рендера; повтор прошёл. Первый CPU-запуск передавал WeatherCheck неверный путь фикстуры; аргумент исправлен, весь повторный CPU-набор прошёл. Невалидная первая версия startup-контроля имела ошибку пакета Mixin; она также сохранена и не засчитывалась как успешный контроль.

## Границы и файлы

Одна видеокарта не заменяет проверку другой аппаратуры/ОС. Совместимость ограничена указанными версиями; произвольные шейдерпаки/LOD-моды и синхронизация облаков между игроками не заявляются. Атлас 4096 занимает 1 ГиБ на пару Iris. Исторический более строгий raw RGB 1e-5 диагностический стресс имел отрицательный результат; основные density/sky/transmission критерии принимались отдельно и код этих путей не менялся.
Исходная сборка, конфиг и фаза погоды сохранены для отката. Хеши 9 файлов профиля, его модов и чекпойнтов проверены; профиль на момент приёмки не изменён. Видео снимается отдельно на максимальных съёмочных настройках; его 60 fps не являются показанием реального игрового FPS.
Подробные локальные данные: лаборатория `cloudscape-rc-20261024`, файлы `output/acceptance.json`, `fps-analysis.json`, `fps-runs.csv`, `soak-summary.json`, входы/логи/CSV каждого `game-stand/runs/*`. В публичный дистрибутив не входят чужие JAR/шейдерпаки, runtime, миры или тестовый мод.
